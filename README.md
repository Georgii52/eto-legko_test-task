# Download speed test (test task)

Консольный скрипт на Node.js + TypeScript: делает N последовательных запросов
к указанному адресу (по умолчанию 10), дожидается **полного** скачивания тела
каждого ответа и печатает среднее время запроса, суммарный объём и скорость
скачивания.

## Запуск

Требуется Node.js ≥ 22.6 (проверено на Node 26). TypeScript исполняется
нативно, отдельная сборка не нужна.

```bash
npm install        # только dev-зависимости для typecheck (typescript, @types/node)
npm start -- https://proof.ovh.net/files/10Mb.dat
# или напрямую:
node src/app/main.ts https://proof.ovh.net/files/10Mb.dat
node src/app/main.ts https://example.com/big.jpg --requests 5
```

`npm run typecheck` — проверка типов (`tsc --noEmit`).

## Единицы измерения

- **Среднее время запроса** — миллисекунды (`ms`). Это время от начала запроса
  до полного получения тела ответа (не только заголовков).
- **Объём** — суммарные байты тел ответов; для чтения форматируются в
  `B / KB / MB` (KB = 1024 B, MB = 1024 KB).
- **Скорость** печатается в двух единицах:
  - `Mbit/s` — мегабиты в секунду, **десятичные** (1 Mbit/s = 1 000 000 bit/s),
    как принято у интернет-провайдеров;
  - `MB/s` — мегабайты в секунду, **двоичные** (1 MB/s = 1 048 576 B/s).

Скорость считается как «все скачанные байты / всё суммарное время запросов» —
то есть это средняя полезная скорость за весь прогон, включая накладные
расходы на установление соединений (TLS и т.п.).

Формула: `speed = (totalBytes * 8 / (totalMs / 1000)) / 1e6` [Mbit/s].

## Структура (FSD, адаптация под CLI/серверную часть)

Классические слои FSD адаптированы: вместо `pages/widgets` — консольный вывод,
слой `app` — точка входа CLI. Правила соблюдены: импорты только сверху вниз
(`app → features → entities → shared`), каждый слой наружу отдаёт API через
`index.ts`.

```
src/
├── app/                        # точка входа, сборка приложения
│   ├── lib/
│   │   └── parse-cli-args.ts   # парсинг и валидация argv
│   └── main.ts                 # CLI: аргументы → прогон → отчёт → код возврата
├── features/
│   └── speedtest/              # фича «замер скорости»
│       ├── lib/
│       │   ├── measure.ts      # один замер + N последовательных (allSettled-семантика)
│       │   ├── stats.ts        # агрегация: время/объём/скорость
│       │   └── report.ts       # консольный отчёт фичи
│       ├── model/
│       │   └── types.ts        # SpeedTestOptions, SpeedTestSummary, MeasureProgress
│       └── index.ts            # публичный API фичи
├── entities/
│   └── measured-request/       # сущность «результат одного замера»
│       ├── model/types.ts
│       └── index.ts
└── shared/
    ├── lib/
    │   └── format.ts           # форматирование байт/миллисекунд
    └── ui/
        └── console.ts          # консоль как «UI-слой» для CLI
```
