# Test tasks

Репозиторий с тестовыми заданиями. Каждое задание — отдельная папка,
каждая запускается независимо (свой `package.json`).

| Папка | Задание | Стек |
|---|---|---|
| [`01-download-speedtest/`](./01-download-speedtest) | Консольный замер скорости скачивания: N последовательных запросов, среднее время, объём, скорость | Node.js ≥ 22.6, TypeScript (нативный запуск), без рантайм-зависимостей |
| [`02-keitaro-campaign-manager/`](./02-keitaro-campaign-manager) | Веб-панель для рекламного трекера Keitaro: создание кампании с 2 потоками (гео → Google, остальное → оффер) + редактор офферов в потоках | Node.js ≥ 22.6, TypeScript, без рантайм-зависимостей; фронт — vanilla JS без сборки |

## Запуск

Внутри каждой папки — свой README с инструкцией и описанием.
